TeachAxo

Учет учеников, оценки и расписание в одном приложении

Простая и современная система для преподавателя: классы, предметы, журнал, расписание, роли доступа и автообновления.

Скачать последнюю версию GitHub репозиторий

Ключевые возможности

Ученики и классы

Карточки по классам, быстрый поиск, перенос учеников между классами и печать списков.

Журнал оценок

Матрица как в Excel: выбор оценок, ввод с клавиатуры и numpad, режим недели или всех дат.

Конструктор расписания

Автоматический расчет времени уроков по сетке с учетом длительности урока и перемены.

Роли и права

Гибкий доступ к разделам и функциям для разных пользователей.

Темы интерфейса

Поддержка светлой и темной темы с переключением в один клик.

Обновления

Автоматическая проверка и установка обновлений через GitHub Releases.

Быстрый старт

  1. Скачайте установщик из релизов.
  2. Установите и запустите TeachAxo.
  3. Добавьте классы и предметы.
  4. Настройте расписание и начните вести оценки.
