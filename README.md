# TeachAxo

Десктопное приложение на Electron для:
- учета учеников и классов;
- выставления оценок в журнале;
- конструктора расписания;
- печати списка учеников и расписания.

## Запуск

1. Установите Node.js LTS (если еще не установлен).
2. В папке проекта выполните:

```bash
npm install
npm start
```

## Технологии

- Electron + renderer на чистом JavaScript;
- Semantic UI CSS;
- SQLite (через внутренний `DatabaseService`);
- Автообновления через GitHub Releases.

## Что уже реализовано

- Авторизация, роли и права доступа.
- Вкладка `Классы`: справочник классов с поиском.
- Вкладка `Ученики`: карточки по классам, модальное окно класса, перенос ученика между классами, печать класса.
- Вкладка `Предметы`: отдельный справочник предметов для расписания.
- Вкладка `Оценки`: матричный журнал (ученики x даты), быстрый выбор оценок (ЛКМ/ПКМ, клавиатура, numpad, `Б`/`Н`), выбор диапазона дат.
- Вкладка `Расписание`: упрощенный конструктор (без недель I/II), автоматический расчет времени по номеру урока, настройка длительности перемены, перерасчет существующих уроков.
- Переключение светлой/темной темы и синхронизация оформления.
- Печать:
  - список учеников по классам;
  - расписание.
- Локальное сохранение в SQLite (без `localStorage`).
- Проверка обновлений при запуске и фоновая проверка в рантайме.

## Обновления приложения

При старте приложения открывается отдельное окно проверки обновлений:
- если обновление найдено, оно скачивается и устанавливается автоматически;
- если обновления нет, запускается основное окно приложения.

### Нумерация релизов

В проекте используется:
- `version` в `package.json` (SemVer, например `1.0.1`);
- `build.buildVersion` (Windows-номер сборки, например `1.0.1.3`).

Для релиза обновления:
1. Обновите `version` и `build.buildVersion` в `package.json`.
2. Соберите приложение:
   ```bash
   corepack yarn dist
   ```
3. Подготовьте архив обновления:
   ```bash
   corepack yarn update:archive
   ```
4. Опубликуйте релиз и загрузите:
   - `dist/TeachAxo-Update-<version>.zip`
   - `dist/latest.yml`
