# TeachAxo

Десктопное приложение на Electron для:
- учета учеников;
- выставления оценок;
- конструктора расписания;
- печати списка учеников и расписания.

## Запуск

1. Установите Node.js LTS (если еще не установлен).
2. В папке проекта выполните:

```bash
npm install
npm start
```

## Что уже реализовано

- Вкладка `Ученики`: добавление, поиск, удаление, хранение контактов.
- Вкладка `Оценки`: выставление оценок по ученикам и просмотр журнала.
- Вкладка `Расписание`: добавление/удаление уроков с сортировкой по дням и времени.
- Печать:
  - список класса;
  - расписание.
- Локальное сохранение данных через `localStorage`.
- Роли, права, пользователи и авторизация.
- Проверка обновлений при запуске через GitHub Releases.

## Обновления приложения

При старте приложения открывается отдельное окно проверки обновлений:
- если обновление найдено, оно скачивается и устанавливается автоматически;
- если обновления нет, запускается основное окно приложения.

### Нумерация релизов

В проекте используется:
- `version` в `package.json` (SemVer, например `1.0.1`);
- `build.buildVersion` (Windows-номер сборки, например `1.0.1.3`).

Для релиза обновления:
1. Обновите `version` и `build.buildVersion` в `package.json`.
2. Соберите приложение `npm run dist`.
3. Загрузите артефакты в новый GitHub Release того же репозитория.
